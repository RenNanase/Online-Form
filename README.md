# JMC Senior Care Registration Form

This project is a modern and responsive multi-step registration form for JMC Senior Care, built with HTML, Tailwind CSS, and GreenSock Animation Platform (GSAP).

## Features

-   **Multi-Step Form:** Guides users through the registration process step-by-step.
-   **Responsive Design:** Looks great on all devices, from desktops to mobile phones.
-   **Custom Color Scheme:** Uses a custom color palette with "Deep Current" (#024059) and "Chalk White" (#E8E6EB).
-   **Smooth Animations:** Utilizes GSAP for smooth transitions and animations.
-   **Input Validation:** Validates user input to ensure data quality.
-   **Terms and Conditions Modal:** Displays the terms and conditions in a modal window.
-   **PDPA Consent Notice:** Asks for user consent to the collection and processing of personal data.
-   **Success Page:** Displays a success message after the user has successfully registered.
-   **NRIC to Date of Birth:** Automatically extracts the date of birth from the user's NRIC.

## How to Use

1.  Clone the repository:
    ```bash
    git clone https://github.com/RenNanase/Online-Form.git
    ```

2.  Open the `new_form.html` file in your web browser.
